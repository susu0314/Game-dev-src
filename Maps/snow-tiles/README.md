32×32 网格主题的雪地瓦片表和雪尖刺 PNG。

用途建议：寒潮路线、积雪地区背景细节和冰冻障碍。

使用注意：类杀戮尖塔地图主要是节点与连线，瓦片仅补充环境，不必为此做地牢行走系统。
