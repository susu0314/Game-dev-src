# Cartography Pack

- 原作者：Kenney
- 来源：https://kenney.nl/assets/cartography-pack
- 核查日期：2026-10-02
- 许可：CC0-1.0（说明见 [署名文件](../../ATTRIBUTION.md)）
- 状态：已保存 15 个文件；Unity 未导入测试。

分叉路线、营地、山地、水体、树林、塔和火山等 14 个地图符号。

用途建议：路线地图底层图例、观测营地、地形事件和气象区域标记。

使用注意：源包为通用奇幻制图；火山属于自然环境例外，并非天气现象。
