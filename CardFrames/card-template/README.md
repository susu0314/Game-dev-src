可拆分的奇幻卡牌面、装饰、数字和文字栏。

用途建议：主卡框可放天气插画；将标题、能量和描述改为 Unity 文本。通用奇幻题材例外。

使用注意：Card.png 是 626×830 的完整图；Update 是拆分部件。带纹理的边框不能默认任意九宫格拉伸。
